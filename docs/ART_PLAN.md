# 美术表现力提升计划

> 2026-11-12 立。原则：延续「程序化生成 + 扁平矢量/像素」路线，零外部素材依赖，非写实。

## P0 · 情感核心（每个玩家必然看到）

| 项 | 内容 | 工作量 |
|---|---|---|
| 人生阶段头像 | 婴儿→童年→青年→中年→老年五阶段：发际线、皱纹、体态渐变；肤色/服饰延续文化圈色板。现状从生到死一张脸 | 中 |
| 分享卡片生成 | Canvas 绘「我这辈子」海报：头像 + 国别 + 享年 + 人生关键词 + 生命色谱条，一键保存。传播力第一短板 | 中 |
| 生命年轮升级 | 结算时间线改可视化年轮：幸福度曲线 + 大事件节点 + 与同龄人对比带。死亡是情感高潮，现在只有列表 | 中 |

## P1 · 氛围系统

| 项 | 内容 | 工作量 |
|---|---|---|
| 时代色调 | 年代世界整页色调随出生年漂移：1950 泛黄胶片 / 1960 高饱和印刷 / 1990 荧光 / 2020 数字冷色。CSS 变量驱动 | 小 |
| 文化圈服饰 pattern | 22 圈传统服饰元素进头像：西非蜡染纹、纱丽披肩、立领盘扣、安第斯几何纹（SVG pattern 库） | 大 |
| 事件卡动效 | 出生/婚姻/死亡等重事件入场动画（死亡墨色晕开） | 小 |

## P2 · 环境细节

| 项 | 内容 | 工作量 |
|---|---|---|
| 天气季节层 | 页面顶部细雨/烈日/落雪程序化动画，跟季节联动 | 小 |
| 出生场景插画 | 程序化小场景：医院/家中土屋/帐篷/稻田边，按国别+城乡切换 | 大 |
| 城乡装饰边框 | 城市天际线 vs 乡村地平线的界面描边 | 小 |

## P3 · 加分项

- **零素材音效**：Web Audio 合成——翻页沙沙、婴儿啼、死亡钟声（可开关）
- **水墨模式**：整站墨色主题
- **人生地图**：迁移事件画成路径线（只有经历过的玩家能看到）

## 执行顺序

1. 分享卡片 + 时代色调（小中成本，管传播和年代氛围）
2. 人生阶段头像 + 生命年轮（情感闭环）
3. 文化圈服饰（大件，事件库冲 2000 后单独一轮）

## 素材策略

- 优先复用开源像素素材库（见 DATA.md 资源清单）
- 开源素材不覆盖的部分（如 22 文化圈服饰纹样）用 AI 生图产出底稿，再程序化简化成 SVG pattern
- 一切产出遵守「非写实」审美红线
