# 八十亿分之一 · One in 8B

> 你出生在哪个国家、是男是女、能活多久、会遇到什么——在你意识到之前，大部分已经被概率决定了。

一款纯前端的「人生概率模拟器」。每次开局，你会被随机投生到 80 亿人中的某一个位置，然后带着这个出身走完一生。

灵感来自 [1in8b.life](https://1in8b.life)，向原作者的创意致敬。

## 玩法

1. **出生**：按真实世界出生分布抽取国籍与性别（当前支持中国、印度、美国、印度尼西亚、巴基斯坦——覆盖全球新生儿约 35%、总人口约 37 亿）
2. **人生**：逐年推进，随机遭遇 150 类人生事件——上学、打工、疾病、地震、海啸、战争、中彩票……每个事件都和你的年龄、国家、性别、家境挂钩
3. **抉择**：部分事件给出选择，选或不选都有代价
4. **结算**：走到死亡那天，看看这一生过成了什么样

## 在线体验

**https://madbarasa.github.io/one-in-8b/**

无需注册，直接开玩。

## 特性

- **150 条人生事件**：覆盖童年、求学、成年空窗、中年、老年、灾害与时代洪流，其中 70 条国别特色事件（美国学贷与医保账单、印尼火山与开斋节返乡、巴基斯坦洪水与板球、中国春运与中考分流、印度嫁妆与 IT 外包）
- **真实统计口径**：出生权重（UN WPP 2024）、分国分性别生命表（经校准对齐 WHO/世行预期寿命数据，五国 10 张表全部 ±1.5 岁内）、死因构成（WHO GHE）、宗教构成（Pew）
- **动态结局**：同类事件依据人物状态产出不同结果
- **程序化像素皮肤（v0.4.0）**：像素小人随年龄进化（襁褓→孩童→少年→成年→暮年）、五国国服配色、城市场景（高楼/摩天楼/宣礼塔）与乡村地貌（稻田/梯田火山/谷仓麦田）按出生国切换、人生天色从晨光到黄昏、死亡像素墓碑——全部 SVG 程序生成，零外部素材
- **零依赖纯前端**：Vanilla JS（ESM），无框架、无构建、无后端、无追踪
- **可离线**：附单文件构建脚本，可打包出一个 HTML 走哪玩哪

## 本地运行

直接用静态服务器伺服仓库根目录（ESM 模块不能 `file://` 直开）：

```bash
npx serve .
# 或
python3 -m http.server
```

生成单文件离线版：

```bash
node scripts/build_standalone.js
```

## 技术栈

| 层 | 选型 |
|---|---|
| 页面 | 原生 HTML + CSS |
| 逻辑 | Vanilla JavaScript（ESM） |
| 数据 | 事件库 / 国家库 / 生命表均为独立 JS 模块 |
| 部署 | GitHub Pages |

```
js/
├── data/        # 事件、国家、生命表、姓名库
├── engine/      # 人生推演引擎
├── ui/          # 界面渲染
├── rng.js       # 随机数
└── main.js      # 入口
scripts/build_standalone.js   # 单文件打包
```
