# 八十亿分之一 · One in 8B

> 你出生在哪个国家、是男是女、能活多久、会遇到什么——在你意识到之前，大部分已经被概率决定了。

一款纯前端的「人生概率模拟器」。每次开局，你会被随机投生到 80 亿人中的某一个位置，然后带着这个出身走完一生。

灵感来自 [1in8b.life](https://1in8b.life)，向原作者的创意致敬。

## 玩法

1. **出生**：按真实世界出生分布抽签——**217 个国家与地区全覆盖**（世界银行 API 实时统计），出生国、性别、城乡、家境、宗教全部按真实分布
2. **人生**：逐年推进，随机遭遇 **1500+ 类人生事件**——学业、求职、恋爱、疾病、灾害、战争、时代洪流，外加 **22 文化圈本土事件**（非洲五圈/中东四圈/亚太五圈/欧洲三圈/美洲大洋洲），每个事件与你的年龄、国家、性别、家境、文化圈挂钩，并标注真实数据出处
3. **抉择**：移民、升学、创业、婚姻——重大节点自己选，选错的代价也是人生的一部分
4. **陪跑**：同一秒出生的另外 4 个婴儿与你并肩走完一生，看命运如何在同样的起点长出完全不同的轨迹
5. **结算**：走到死亡那天，回顾这一生，与你同龄的人对照

## 特性

- **217 国真实统计**：出生权重、分国分性别生命表（自动生成器校准至世行预期寿命 ±0.3 岁内）、婴儿死亡率、死因构成、城市化率、人均 GDP（PPP）——全部来自世界银行 API 最新数据
- **基尼系数收入模型**：家庭年收入按各国收入分布（对数正态）抽取，PPP 国际元与美元购买力双显示
- **1500+ 条人生事件**：通用线 + 中国 176 / 美国 94 / 印度 64 / 印尼巴 87 条国别特色 + **22 文化圈 430 条本土事件**（西非命名礼、之角咖啡仪式、东非 M-PESA、阿拉伯斋月、波斯诺鲁孜、儒家补习、东南亚布施、西语亡灵节、巴西狂欢节、太平洋海平面……），全部手写文案 + 数据出处
- **同龄人陪跑**：4 个同秒出生的婴儿独立模拟，与你实时对照（官方同款机制）
- **人生暂停点**：5/15/30/50/70 岁停下来回答一个问题，你的留言保存在本地
- **移民抉择**：出国换一个国家继续人生——生命表、收入基准、事件池全部切换
- **教室模式**：一键缓和沉重主题（战争/成瘾/暴力事件降权），适合课堂使用；死亡卡附各国心理援助热线
- **程序化像素皮肤**：像素小人随年龄进化、七地区组国服配色、城市天际线与乡村地貌按出生国切换——全部 SVG 程序生成，零外部素材
- **零依赖纯前端**：Vanilla JS（ESM），无框架、无构建、无后端、无追踪
- **可离线**：附单文件构建脚本，可打包出一个 HTML 走哪玩哪

## 本地运行

直接用静态服务器伺服仓库根目录（ESM 模块不能 `file://` 直开）：

```bash
npx serve .
# 或
python3 -m http.server
```

生成单文件离线版：

```bash
node scripts/build_standalone.js
```

## 技术栈

| 层 | 选型 |
|---|---|
| 页面 | 原生 HTML + CSS |
| 逻辑 | Vanilla JavaScript（ESM） |
| 数据 | 事件库 / 国家库 / 生命表均为独立 JS 模块 |
| 部署 | GitHub Pages |

```
js/
├── data/        # 事件、国家、生命表、姓名库
├── engine/      # 人生推演引擎
├── ui/          # 界面渲染
├── rng.js       # 随机数
└── main.js      # 入口
scripts/build_standalone.js   # 单文件打包
```
